Burn subtitles into a video for free – no watermark, 3 offline ways

“Burning in” (also called hardcoding) means the subtitles become part of the picture. That is what you want for TikTok, Reels, Shorts or WhatsApp: soft subtitle tracks are ignored there. Online “free” burners usually add a watermark or a size limit and upload your video. These three tools are free, run on your own PC and add nothing.

You need: the video and a subtitle file (.srt or .ass). No subtitle file yet? Skip to “I have no subtitles yet”.

1. HandBrake – easiest (Windows, Mac, Linux)

  1. Open HandBrake (free, open source, handbrake.fr) and drag your video in.
  2. Open the Subtitles tab → Tracks → Import Subtitle and pick your SRT or ASS file.
  3. Tick Burn In in that row. Only one track can be burned in.
  4. Choose a preset (e.g. Fast 1080p30; it keeps the aspect ratio, so 9:16 stays 9:16), set the file name, click Start Encode.

Styling: an SRT gets HandBrake’s plain white font. For your own font, colour and outline, import an .ass file – HandBrake keeps its styles.

2. FFmpeg – one command, full control

If FFmpeg is installed (free, ffmpeg.org), open a terminal in the folder with your files:

ffmpeg -i video.mp4 -vf subtitles=subs.srt -c:a copy video_subtitled.mp4

Bigger, bold captions with an outline, centred lower third:

ffmpeg -i video.mp4 -vf "subtitles=subs.srt:force_style='FontName=Arial,FontSize=18,Bold=1,Outline=2,MarginV=60'" -c:a copy video_subtitled.mp4

With an .ass file use -vf ass=subs.ass; the styles inside the file are used. Tip: on Windows, keep the subtitle file in the same folder and use a simple file name – paths with C:\ need extra escaping in the filter.

3. VLC – if it is already installed

  1. Media → Convert / Save, add the video, tick Use a subtitle file and pick the SRT.
  2. Click Convert / Save, choose a profile (Video – H.264 + MP3 (MP4)) and open its settings (wrench icon).
  3. On the Subtitles tab tick Subtitles and Overlay subtitles on the video, save, set a destination file and click Start.

Works for quick jobs, but it is slow and fails more often than HandBrake (missing audio or no subtitles in the output are common complaints). If it fails, use way 1.

I have no subtitles yet

FAQ

Will burned-in subtitles lower the video quality?

The video is re-encoded, so there is a small loss. With HandBrake’s default quality (RF 20–22) or FFmpeg’s default x264 settings it is not visible on a phone.

Can I remove burned-in subtitles later?

No – they are part of the picture. Keep the original video and the subtitle file.

SRT or ASS?

SRT is plain text with times, every tool reads it. ASS also stores font, colour, outline, position and per-word effects – use it when the look matters.

How do I burn subtitles on Android or iPhone?

Mobile editors such as CapCut can add captions on the phone; free tiers may limit styles or exports. The offline tools on this page are for desktop.
