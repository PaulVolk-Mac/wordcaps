# WordCaps Studio – offline word-by-word captions for Windows

**WordCaps Studio** is a small Windows app that adds animated, word-by-word highlighted captions to your videos (TikTok, YouTube Shorts, Instagram Reels). Think CapCut- or Submagic-style captions, but **100 % offline**, with **no subscription, no account, no upload and no watermark**.

- Website & FAQ: https://paulvolk-mac.github.io/wordcaps/
- Get it (itch.io, €12.99 one-time): https://jaulana.itch.io/wordcaps

## What it does
- Speech-to-text runs on your PC (open Whisper model), captions are burned in with FFmpeg.
- 8 caption looks: classic, pop, box, minimal, bounce, karaoke, single word, neon glow – any colour, any installed font, size S–XL, position bottom/middle/top, 1–5 words on screen.
- Keywords (numbers, names) pop in a second colour.
- Check and fix the text before it is burned in.
- Batch mode for several videos at once.
- Exports MP4 plus SRT and ASS for CapCut, Premiere Pro and DaVinci Resolve.
- Windows 10/11, 64-bit. NVIDIA GPU optional (faster), works on CPU.
