How to import an SRT file into CapCut

Auto captions locked behind Pro, wrong words, or you simply want captions made on your own PC? You can bring your own subtitle file. This guide shows where the import is, how to make a good SRT for free (even one word per caption), and how to fix the problems that come up most often.

Step 1: Make an SRT file (free)

An SRT is a plain text file with numbered blocks, a time range and the text, for example:

1
00:00:00,480 --> 00:00:01,920
This is how you import

2
00:00:01,920 --> 00:00:03,100
your own captions

Free ways to create one:

  • Whisper (command line): OpenAI's open-source speech recognition runs fully on your PC. After installing it (Python, pip install openai-whisper, plus FFmpeg), run
    whisper video.mp4 --model small --language en --output_format srt
    Bigger models (medium, large) are more accurate but slower.
  • One word per caption: for the fast TikTok look, add word timestamps:
    whisper video.mp4 --model small --output_format srt --word_timestamps True --max_words_per_line 1
    Use --max_words_per_line 3 for short chunks instead.
  • Subtitle Edit (Windows, with a window): open the video, use Video → Audio to text (Whisper), check the text, then save as SubRip (.srt).

Step 2: Import the SRT into CapCut

CapCut Desktop (Windows / Mac): open your project, go to Captions and pick the option to import or add a local caption file, then select your .srt. The lines appear as a caption track on the timeline.

CapCut Web: open the project, choose Captions in the left toolbar and upload the .srt file.

CapCut Mobile: CapCut's own help says the mobile app cannot import subtitle files. Do the import on desktop or web, save the project to your CapCut cloud space, then open it on your phone.

Menu names change between versions. If you don't see the option, look under Text as well as Captions, and update the app.

Step 3: Style all captions at once

Select one caption on the track and change font, size, colour, stroke and position. In most versions the change can be applied to all captions of the track. Animating single words needs much more manual work.

Import problems and fixes

The file can't be selected or nothing happens

  • Windows hides file extensions. A file shown as captions.srt may really be captions.srt.txt. Turn on View → File name extensions in Explorer and rename it.
  • The file must be plain text. Don't save it from Word; use Notepad or Subtitle Edit.

Strange characters instead of ä, é, ñ

Save the file as UTF-8. In Notepad: Save as → Encoding: UTF-8.

Captions are out of sync

  • SRT times count from the start of the audio they were made from. Make the SRT from the final edit (export the cut video first), not from the raw clip.
  • If everything is shifted by the same amount, select the whole caption track and move it so it starts at the right point.
  • Check the time format: 00:00:01,920 with a comma before the milliseconds. A dot (01.920) is WebVTT style and can fail.

Only part of the file shows up

One broken block can stop an importer. Every block needs a number, a valid time line with -->, at least one text line and an empty line after it. Subtitle Edit's Tools → Fix common errors repairs most of this.

FAQ

Can I import an SRT file into CapCut on my phone?

Not directly. Import on CapCut Desktop or Web, save the project to the cloud space and open it on the phone.

Do I need CapCut Pro to import an SRT?

Importing your own file is separate from auto captions. Check your own app version and region – what is free changes often.

How do I get one word per caption?

Whisper with --word_timestamps True --max_words_per_line 1 writes one word per SRT block.

Why are my imported captions out of sync?

The SRT was made from a different cut, or the caption track does not start at the right point. Make the SRT from the final edit or move the whole track.
