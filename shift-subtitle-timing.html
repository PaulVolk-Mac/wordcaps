How to shift subtitle timing (SRT offset)

The words are right, but every line shows up a second too late or too early. That is the most common subtitle problem, and it is quick to fix: add one offset to every time stamp. This guide shows five free ways, from a browser tool without install to a one-line FFmpeg command, and how to tell a simple offset from drift that needs a different fix.

First: which direction?

  • Text comes after the words → subtitles are late → use a negative offset (e.g. -1.5 s).
  • Text comes before the words → subtitles are early → use a positive offset (e.g. +0.8 s).

To find the amount, play the video, note the time when a clear line is spoken (say 0:12.4) and the start time of that line in the SRT (say 0:13.9). The difference, here −1.5 s, is your offset.

Same gap at the start and at the end? Then a shift is all you need. Gap grows during the video? Jump to subtitles drift out of sync.

1. Online in the browser (no install, no upload)

Our free subtitle converter has a Shift timing field:

  1. Drop your .srt, .vtt or .ass file on the page or paste the text.
  2. Type the offset in seconds under Shift timing, or use the − / + buttons (0.1 s per click).
  3. Pick the output format (SRT, VTT, ASS or plain text) and download.

Everything runs in your browser. The file never leaves your PC, there is no sign-up and no watermark. You can convert and shift in one step, for example SRT → VTT for a web player.

2. VLC: while watching (not saved)

Press H to delay the subtitles and G to show them earlier, 50 ms per press (on a Mac the keys can differ, see VLC's hotkey settings). The menu way is Tools → Track Synchronization → Subtitle track synchronization. This only changes playback. Close the video and the offset is gone, so for a file you want to share or upload use one of the other ways.

3. HandBrake: offset while importing

If you encode the video with HandBrake anyway: open the Subtitles tab, import your SRT and set Offset (ms) in the import options, for example -1500 for 1.5 s earlier. You can add the track as a soft subtitle or burn it in. The original SRT file stays unchanged.

4. Subtitle Edit (Windows, free)

Open the SRT, then Synchronization → Adjust all times. Enter the time, choose Show earlier or Show later and save. Subtitle Edit also has the drift tools from the section below.

5. FFmpeg: one command

With FFmpeg installed, -itsoffset before the input moves every time stamp:

ffmpeg -itsoffset 1.5 -i in.srt out.srt     (1.5 s later)
ffmpeg -itsoffset -0.5 -i in.srt out.srt    (0.5 s earlier)

We tested both lines: a line at 00:00:01,000 moves to 00:00:02,500 and 00:00:00,500. Handy for many files in a batch script.

Subtitles drift out of sync (a shift won't fix it)

If the first lines fit and the last ones are several seconds off, the subtitles were made for a different version of the video:

  • Different frame rate (23.976, 24, 25 fps): the gap grows evenly. In Subtitle Edit use Synchronization → Change frame rate, e.g. from 25 to 23.976.
  • Different cut (intro removed, ad break, director's cut): the gap jumps at one point. Use a two-point sync (Subtitle Edit: Point sync) or shift only the lines after the jump.
  • Your own edit: SRT times count from the start of the audio they were made from. If you cut the video after making the SRT, make it again from the final export.

Common problems after shifting

  • Lines before 0:00: with a large negative offset the first lines can end up before the start. Delete those lines or use a smaller offset; some players reject negative times.
  • Comma vs dot: SRT uses 00:00:01,500 (comma), WebVTT uses 00:00:01.500 (dot). Save in the format your player expects.
  • Strange characters (Ã¤ instead of ä): save the file as UTF-8.

FAQ

How do I shift an SRT file by a few seconds?

Open the subtitle converter, drop the file, type the offset under Shift timing and download. Nothing is uploaded.

Positive or negative offset – which one do I need?

Text after the words = late = negative offset. Text before the words = early = positive offset.

The subtitles drift apart over time. Will a shift fix that?

No. That is a frame-rate or cut difference. Use a frame-rate change or a two-point sync, see drift.

Can I shift subtitles in VLC permanently?

No, the VLC delay (G / H) only applies while you watch. Change the file with a converter, Subtitle Edit or FFmpeg.
